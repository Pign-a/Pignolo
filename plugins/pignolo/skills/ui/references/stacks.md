# Stack translation
Use when: the project is not React with Radix, or only part of it is (Astro landing, mobile app, Vue, Svelte). Same behavior in the stack's own primitives, never React code pasted in.
Choose: read the stack from the project's CLAUDE.md or manifest. React/Next with Radix: copy the kit (`kit/README.md`). Anything else: `motion-and-microinteractions.md` and the pattern sheets are the specification (three tiers, press 0.97, state matrix, exit faster than enter, interruptible, reduced motion). design.md tokens win over every number here.

## Spring conversion
Kit tiers are Motion `visualDuration` plus `bounce`. Motion's period is 1.2 x visualDuration (motion-dom 14.6.0, read and run); SwiftUI and Flutter `duration` is the period itself. For Apple-style libraries use `duration = 1.2 x visualDuration`:

    mass = 1;  stiffness = (2*PI/duration)^2;  damping = 4*PI*(1-bounce)/duration;  dampingRatio = 1-bounce

Agreeing sources: Flutter `withDurationAndBounce`, Compose `SpringSimulation` (frequency sqrt(stiffness), seconds), Reanimated physics mode (seconds). Motion's generator matches the formula within 0.001.

| Tier | vd, bounce | Apple duration | stiffness | damping | ratio | 1% settle |
|---|---|---|---|---|---|---|
| direct | 0.22, 0.15 | 0.264 s | 566.4 | 40.46 | 0.85 | 0.187 s |
| momentum | 0.35, 0.20 | 0.420 s | 223.8 | 23.94 | 0.80 | 0.425 s |
| data | 0.45, 0 | 0.540 s | 135.4 | 23.27 | 1.00 | 0.570 s |

Conflicts:
- Using the tier numbers as Apple duration (no x1.2) is 1.2x faster (direct: stiffness 815.7, settles 0.156 s). Use the table.
- WWDC23 page text prints `damping = 1 - 4*PI*bounce/duration` (bounce >= 0), which gives 1 at bounce 0, not 4*PI/duration; Flutter's source says it matches SwiftUI. Use the formula above. For bounce < 0 Apple and Flutter differ; the tiers never go negative.
- Reanimated `duration` is energy-based (settles at 1.5x); matching the kit needs 405, 683, 709 ms, no constant ratio. Use physics mode, `mass: 1` (default is 4).
- Compose has only `dampingRatio` and `stiffness`. Svelte `Spring` is unit-less with no documented conversion; use Motion vanilla.

## Per stack
V = built and run in `pignolo-eval/stack-spikes`; D = from docs, not run.

**React/Next**: kit as is. Reduced: `MotionConfig reducedMotion="user"`.

**Astro (landings)**: CSS first, no framework JS in static sections.
- Tier: `linear()` generated by the solver below (widely available, MDN); transition duration is the 1% settle: 187, 425, 570 ms.
- Entry `@starting-style` (Baseline 2024). Press `:active { scale: .97 }`; lift on `translate` inside `@media (hover: hover)`; focus `:focus-visible` with the focus tokens.
- Reduced: `prefers-reduced-motion` drops translate and scale, keeps a 120 ms fade.
- Scroll reveal: `@supports (animation-timeline: view())`; MDN says limited availability, so content must show without it.
- Pages: `<ClientRouter />` from `astro:transitions` in `<head>`; it falls back where unsupported and is off under reduced motion (Astro docs, D).
- Islands: `client:visible` below the fold, `client:idle` secondary, `client:load` only above the fold. A React island may reuse the kit. Scoped Astro CSS does not reach island markup: share control CSS globally.
- Tokens: copy `kit/tokens.css` or map design.md.

    const k=(2*Math.PI/(1.2*vd))**2, z=1-b, w=Math.sqrt(k), wd=w*Math.sqrt(1-z*z)
    const x=t=>z>=1?1-Math.exp(-w*t)*(1+w*t):1-Math.exp(-z*w*t)*(Math.cos(wd*t)+z*w/wd*Math.sin(wd*t))
    // T = last t with |1-x(t)|>0.01; emit linear(x(0), x(T/32), ... 1) and T as the duration (V)

    .btn { transition: translate var(--spring-direct-duration) var(--spring-direct), scale 200ms var(--ease-decelerate); }
    @media (hover: hover) { .btn:hover { translate: 0 -2px; } }
    .btn:active { scale: .97; transition-duration: var(--spring-direct-duration), 70ms; }   /* V */

V: Astro 7.4.2 build in Chrome 155, no console errors; hover `-2px`, press `0.97`, reduced motion `0px` and `1`; `client:visible` island hydrated.

**Vue, Svelte (D)**: `motion-v` takes kit numbers: `:transition="{ type: 'spring', visualDuration: 0.22, bounce: 0.15 }"`, `MotionConfig reducedMotion="user"`. Svelte: Motion vanilla `animate(el, to, { type: "spring", visualDuration, bounce })`. Radix equivalents Reka UI (Vue) and Bits UI (Svelte), unverified.

**Flutter (V)**: Flutter 3.47.4, Dart 3.13.3, 7 widget tests pass (spring moves, 1% settle in range, second tap keeps position and velocity, reduced motion jumps with no travel, press 0.97).
- Tier: `AnimationController.unbounded` plus `SpringSimulation(spec, c.value, target, c.velocity)`. Implicit widgets take curves only: use them for fades.
- Press: `Listener` pointer down and up, not `onTapDown` (up to 100 ms late). Hover: `MouseRegion` or `FocusableActionDetector.onShowHoverHighlight`, desktop and web only. Focus: `onShowFocusHighlight`.
- Overlays: `showModalBottomSheet`, `showDialog`, `SnackBar`, `MenuAnchor`. Reduced: `MediaQuery.maybeDisableAnimationsOf(context)`. A11y: `Semantics(toggled:, onTap:)`.
- Tokens: colors to `ColorScheme`, springs to `PignoloMotion`. Material `Easing.standard`, `standardDecelerate`, `standardAccelerate` equal design.md's curves; `Durations.short4` is 200 ms.

    abstract final class PignoloMotion {
      static SpringDescription _t(double vd, double b) => SpringDescription.withDurationAndBounce(
          duration: Duration(milliseconds: (vd * 1.2 * 1000).round()), bounce: b);
      static final direct = _t(0.22, 0.15), momentum = _t(0.35, 0.2), data = _t(0.45, 0);
    }
    void springTo(AnimationController c, SpringDescription s, double to, {required bool reduced}) =>
        reduced ? (c..stop()..value = to)
                : c.animateWith(SpringSimulation(s, c.value, to, c.velocity, snapToEnd: true));

**SwiftUI (D)**: `.spring(duration: 0.264, bounce: 0.15)`. Presets: `.smooth` bounce 0, `.snappy` 0.15, `.bouncy` 0.3, so direct is `.snappy(duration: 0.264)` and data `.smooth(duration: 0.54)`. A new spring on the same property keeps velocity. Press: `ButtonStyle` with `isPressed` and `.scaleEffect`. Reduced: `@Environment(\.accessibilityReduceMotion)`, swap movement for opacity. Also `matchedGeometryEffect`, `.presentationDetents`, `.sensoryFeedback(.selection, trigger:)`.

**Compose (D)**: `spring(dampingRatio = 0.85f, stiffness = 566f)`. Press: `collectIsPressedAsState()` into `animateFloatAsState`. Hover and focus: `hoverable` and `focusable` on one `MutableInteractionSource`. `animateContentSize`; lists `Modifier.animateItem(placementSpec = spring(...))` with keys; `ModalBottomSheet`; `minimumInteractiveComponentSize()` (48 dp). Reduced motion API and haptics (`LocalHapticFeedback`): not found in the docs, unverified.

**React Native (D)**: `withSpring(to, { mass: 1, stiffness: 566.4, damping: 40.46, reduceMotion: ReduceMotion.System })` (System is the default and skips the animation). `useReducedMotion()`. Press: Gesture Handler `Gesture.Tap()` into a shared value. Targets: `Pressable` with `hitSlop`.

## Mobile
- Targets 44 pt iOS, 48 dp Android. No hover: give hover lift and tooltips a long-press or pressed equivalent.
- Respect safe areas on every edge.
- Drive springs from gesture velocity; a tap mid-motion retargets, never restarts.
- Haptics on commit only (switch, drop), never on hover or scroll.
- Never claim the edge-swipe back gesture; sheets and modals close with back.
