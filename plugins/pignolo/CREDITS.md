# Credits

Pignolo's idea-development step (section 1 of the `start` skill) was shaped by reading two MIT-licensed skills. Nothing was copied: own text only.

- Matt Pocock's `grilling` / `grill-me` skill (MIT): the ideas of putting a recommended answer next to each question and of settling by reading the code whatever the code can answer.
- Jesse Vincent's `brainstorming` skill in `obra/superpowers` (MIT): the ideas of reading the context first, asking one question at a time and proposing approaches with trade-offs before the design.
