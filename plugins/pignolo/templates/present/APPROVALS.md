# Aprobaciones de plantillas de presentación

Cada plantilla de esta carpeta la revisa y la aprueba el autor antes de que pignolo la use (spec §4.6). Una plantilla sin una línea de aprobación acá, con la misma versión y el mismo sha256, no se usa: ese tipo de contenido cae a texto. Cambiar una plantilla aprobada exige aprobarla de nuevo.

Formato de cada línea de aprobación, una por formato y versión (la última de cada formato manda): un guion, el formato (simple, ui, infra o decision), "v" y la versión, la palabra "aprobado" con la fecha AAAA-MM-DD, y "sha256" con el hash del archivo .html, separados por rayas largas.
