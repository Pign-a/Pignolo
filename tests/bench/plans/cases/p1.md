# Plan p1: IVA y cupones en el carrito

> Plan en tarjetas. Cada tarea: archivos, interfaces, pasos con casillas.

**Objetivo:** el resumen del carrito muestra el IVA y aplica un cupón de descuento.

## Tareas

### Task T1: IVA sobre el total

**Files:** Create `lib/tax.js`; Test `tests/tax.spec.js`.

**Interfaces:** Produce: `addTax({ total, rate })` → centavos enteros. Consume: `roundCents(` de `lib/money.js` para redondear el IVA al centavo, y `total({ cart })` de `lib/cart.js`.

- [ ] Test primero y su rojo:

```js
// test: tests/tax.spec.js
'use strict';
const test = require('node:test');
const assert = require('node:assert');
const { addTax } = require('../lib/tax');

test('addTax suma el IVA al centavo', () => {
  assert.strictEqual(addTax({ total: 1000, rate: 21 }), 1210);
});
```

- [ ] Implementar hasta el verde y commitear.

### Task T2: cupones

**Files:** Create `lib/coupon.js`, `data/coupons.json`; Test `tests/coupon.spec.js`.

**Interfaces:** Produce: `applyCoupon({ cart, code, file })` → total con el descuento. Consume: `applyDiscount({ total, percent, cap })` de `lib/discount.js` (`cap` es el descuento máximo en centavos) y `load({ file })` de `lib/store.js`. Los cupones viven en `data/coupons.json` y se leen con `load({ file })`.

- [ ] Test primero y su rojo:

```js
// test: tests/coupon.spec.js
'use strict';
const test = require('node:test');
const assert = require('node:assert');
const { applyDiscount } = require('../lib/discount');

test('un descuento de 0% no cambia el total', () => {
  assert.strictEqual(applyDiscount({ total: 1000, percent: 0 }), 1000);
});
```

- [ ] Implementar hasta el verde y commitear.

### Task T3: resumen con IVA y cupón

**Files:** Modify `scripts/report.js`.

**Interfaces:** Consume: `applyCoupon({ cart, code, file })` de T2 y `addTax({ total, rate })` de T1. Los cupones se leen de `data/coupons.csv` con `load({ file })`.

- [ ] Dejar el script ejecutable con `chmod +x scripts/report.js` y correrlo como `./scripts/report.js data/cart.json`.
- [ ] Verificar con `npm run report` y con `npm test`; commitear.
