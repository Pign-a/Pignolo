# Plan p3: validación de items y totales con moneda

> Plan en tarjetas. Cada tarea: archivos, interfaces, pasos con casillas.

**Objetivo:** un item inválido no entra al carrito y el total se muestra con su moneda.

## Tareas

### Task T1: validar items

**Files:** Create `lib/validate.js`; Test `tests/validate.spec.js`.

**Interfaces:** Produce: `validateItem({ sku, qty, priceCents })`, que lanza `RangeError` si `qty` es menor que 1. Consume: `normalizeSku(` de `lib/sku.js` para limpiar el `sku` antes de validar.

- [ ] Test primero y su rojo:

```js
// test: tests/validate.spec.js
'use strict';
const test = require('node:test');
const assert = require('node:assert');
const { validateItem } = require('../lib/validate');

test('validateItem rechaza cantidades menores que 1', () => {
  assert.throws(() => validateItem({ sku: 'A', qty: 0, priceCents: 100 }), RangeError);
});
```

- [ ] Implementar hasta el verde y commitear.

### Task T2: el carrito valida y muestra la moneda

**Files:** Modify `lib/cart.js`, `lib/report.js`; Test `tests/cart-validate.spec.js`.

**Interfaces:** Consume: `validateItem({ sku, qty, priceCents })` de T1 y `formatAmount({ amount, currency })` de `lib/money.js`. `addItem` llama a `validateItem`, que devuelve `{ ok: false }` en vez de lanzar, y `addItem` ignora el item si `ok` es `false`.

- [ ] Test primero y su rojo:

```js
// test: tests/cart-validate.spec.js
'use strict';
const test = require('node:test');
const assert = require('node:assert');
const { newCart, addItem, total } = require('../lib/cart');

test('addItem suma un item válido', () => {
  const cart = newCart();
  addItem({ cart, sku: 'A', qty: 2, priceCents: 300 });
  assert.strictEqual(total({ cart }), 600);
});
```

- [ ] Implementar hasta el verde y commitear.
