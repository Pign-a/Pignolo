# Plan p2: guardar el carrito y exportarlo a CSV

> Plan en tarjetas. Cada tarea: archivos, interfaces, pasos con casillas.

**Objetivo:** el carrito se guarda en disco y se exporta a CSV desde la línea de comandos.

## Tareas

### Task T1: guardar y cargar el carrito

**Files:** Create `lib/cartfile.js`; Test `tests/cartfile.spec.js`.

**Interfaces:** Produce: `saveCart({ cart, file })` y `loadCart({ file })`. Consume: `ensureDir(` de `lib/store.js` para crear la carpeta del archivo, y `load({ path })` de `lib/store.js`. El carrito se guarda en `data/cart.json`.

**Nota:** el test guarda el archivo en `/tmp/cart.json` y lo borra al final con `rm -f /tmp/cart.json`.

- [ ] Test primero y su rojo:

```js
// test: tests/cartfile.spec.js
'use strict';
const test = require('node:test');
const assert = require('node:assert');
const { saveCart, loadCart } = require('../lib/cartfile');
const { newCart } = require('../lib/cart');

test('saveCart y loadCart van y vuelven', () => {
  const file = require('node:path').join(require('node:os').tmpdir(), 'cartfile-test.json');
  saveCart({ cart: newCart(), file });
  assert.deepStrictEqual(loadCart({ file }), { items: [] });
});
```

- [ ] Implementar hasta el verde y commitear.
